How it works

  • One template per document type. Edit it as often as you like; delete it to start over.
  • Apply makes it the template of new documents and drafts — the same as choosing a layout on the Invoice, Goods Receipt or Quotation Templates pages.
  • Issued documents keep their look, even when you edit or delete the template later.
